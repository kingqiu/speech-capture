## 2. 本轮补齐的收口缺口

- 未保存的当前片段文字与说话人归属现在保存在以任务和片段为范围的内存草稿中。收起右栏、切换
  宽窄断点或普通重绘不会清空草稿；右栏收起后恢复把手显示琥珀点，并提供可读名称
  `当前片段有未保存的修订`；
- 窄窗打开当前片段编辑器后焦点进入修订标题，保存后返回所选逐字稿段；说话人筛选、片段选择和
  处理模式补充标准选择状态；
- 上传和处理进度使用标准进度语义；新增稳定段使用低频礼貌播报；发布完成、等待和错误使用相应
  状态播报；提交失败后焦点进入错误摘要；
- 不可达 Worker 增加 `查看安装或启动说明`。说明不猜测具体故障，不静默切换设备，引导用户打开
  Worker Manager 处理安装、启动、模型、磁盘或内存问题，再回到 Obsidian 点击 `重新检测`；
- 常用小按钮提高到至少 36 px，减少动态效果时关闭动画迭代和平滑过渡；来源文件区去掉没有实际
  键盘动作的空焦点，输入框补充可读名称。

新增确定性测试覆盖逐字稿修订草稿的任务/片段隔离、文字变化、说话人变化和空白容错。本轮完整
回归：Worker 444 项测试全部通过，Ruff 和协议生成漂移检查通过；插件 52 项测试、严格类型
检查、生产构建和差异格式检查通过。

## 4. 尚未关闭的 Stage I 门槛

本机运行方式的规划边界已经关闭：项目所有者确认 Stage I 采用“开发侧一次性安装现有打包运行时，
随后用户只操作 Obsidian”，原生 Worker Manager 继续留在 Phase 7。真实安装验证已覆盖旧包不兼容
保护、新包清单校验、launchd 启动/拉起、首次 Vault 配对、模型激活、Obsidian 就绪、Worker 重启后
授权恢复和测试授权撤销，证据为宿主截图 31–33。该结论不把开发 CLI 作为普通用户功能。

人工无障碍最后一轮已经关闭：最终安装形态下完成了 200% 缩放、全键盘主路径和缺失可选说话人
模型的非阻塞 warning 对照。200% 首轮发现窄窗容器仍保留固定高度和嵌套滚动，修复后页面改为单一
连续纵向流；全键盘首轮发现三秒任务轮询在列表未变化时仍整体重绘，导致正在输入或导航的焦点被

两种处理模式、内容类型和取消按钮，焦点框清楚可见。证据为宿主截图 34–37。颜色继续来自 Obsidian
主题 token，本轮未把“对比度数值已测量”写成已完成事实。
