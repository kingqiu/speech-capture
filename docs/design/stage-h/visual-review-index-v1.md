## 5. 共同视觉约束

- 暗色墨绿、低对比边框、8–10px 圆角、紧凑无衬线工作台；
- 绿色只表示就绪/安全/接受，蓝色只表示处理中/当前选择，琥珀表示注意或不确定，红色只表示
  失败或被删除的差异；
- 状态同时使用文字和图标，不依赖颜色；
- 主动作每屏只有一个；卡片点击已经能完成的动作不再增加同义按钮；
- 后续视觉稿继续使用合成内容，批准前不进入 Stage I。
